# One Batch Family Website

A PHP + MySQL website built with HTML5, CSS3, Bootstrap 5, and JavaScript.

## Suggested Project Structure

- `index.php` — Home page
- `config/` — Database and application configuration
- `assets/` — CSS, JS, images, videos, audio, uploads
- `includes/` — Shared header, footer, scripts, navbar
- `pages/` — Site pages
- `auth/` — Authentication pages
- `members/` — Member-related pages
- `memories/` — Year-based memory pages
- `controllers/` — Business logic controllers
- `models/` — Data models
- `admin/` — Admin dashboard and management pages
- `api/` — JSON endpoints and AJAX handlers
- `helpers/` — Utility and helper scripts
- `database/` — SQL schema and seed files
- `user/` — User dashboard and profile pages
